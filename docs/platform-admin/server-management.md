# Server Management

Platform admins can manage all servers on the Nexus instance.

## Available Actions

- **List servers** — View all servers with owner, member count, and creation date
- **Delete servers** — Remove a server and all its data (channels, messages, roles)
- **Assign orphans** — Reassign ownership of servers whose owner has been deleted

## Access

Available in the **Platform Admin** tab for the user designated by `PLATFORM_ADMIN`.
