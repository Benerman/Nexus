# User Management

Platform admins can manage all user accounts on the Nexus instance.

## Available Actions

- **List users** — View all registered accounts
- **Reset passwords** — Reset a user's password
- **Delete accounts** — Remove a user account and associated data

## Access

Available in the **Platform Admin** tab for the user designated by `PLATFORM_ADMIN`.
