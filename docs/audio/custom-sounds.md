# Custom Sounds

Personalize your voice experience with custom join/leave sounds.

## Per-User Join/Leave Sounds

Upload custom audio files that play when you join or leave a voice channel, replacing the default two-tone beeps.

Configure in **Settings → Audio → Custom Sounds**.

## Server Soundboard Sounds

Server admins can upload custom sounds to the server soundboard for all members to use.

## Audio Format

Supported audio formats depend on browser support. Common formats: MP3, WAV, OGG.
