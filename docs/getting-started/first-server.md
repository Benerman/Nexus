# Create Your First Server

After [installing Nexus](quick-start.md) and creating an account, you can set up your first server.

## Creating a Server

1. Click the **+** button in the server sidebar
2. Enter a server name (3–32 characters)
3. Optionally choose an icon emoji or upload a custom image
4. Click **Create**

Nexus automatically creates default structure for every new server:

### Default Categories and Channels

| Category | Channels |
|----------|----------|
| GENERAL | #general (text), #announcements (text) |
| VOICE | Lounge (voice), Gaming (voice) |

### Default Roles

| Role | Position | Permissions |
|------|----------|-------------|
| @everyone | 0 | View, send messages, attach files, join voice, read history, add reactions, create invites |
| Admin | 1 | All 19 permissions enabled |

You (the server creator) are the **server owner** and automatically have all permissions regardless of roles.

## Inviting Members

1. Right-click the server name or open **Server Settings**
2. Go to **Invites**
3. Click **Create Invite** — generates a unique invite link
4. Share the link with others

Invite options:
- **Max uses** — Limit how many times the link can be used (0 = unlimited)
- **Expiration** — Set when the invite expires

## Customizing Your Server

After creation, you can customize through **Server Settings**:

- **Server name and icon** — Update the display name and icon
- **Description** — Add a server description (up to 256 characters)
- **Create channels** — Add text and voice channels, organize into categories
- **Create roles** — Set up roles with custom colors, names, and permissions
- **LAN mode** — Enable for local network deployments (disables external features like GIF search)
