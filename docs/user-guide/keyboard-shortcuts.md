# Keyboard Shortcuts

> This feature is planned but not yet implemented. This page will be updated when keyboard shortcuts are added to Nexus.

## Planned Features

- Navigation shortcuts for channels and servers
- Message action shortcuts (edit, reply, delete)
- Voice control shortcuts
- Configurable key bindings
- Shortcuts modal accessible via Ctrl+/
