# Notifications

## Unread Indicators

Channels with unread messages show a bold name and an unread dot in the channel list. DM conversations show unread counts.

## Read State

Nexus tracks read state per-user per-channel. Opening a channel marks it as read. DM read states are tracked separately.

## Typing Indicators

When someone is typing in a channel or DM, a typing indicator appears below the message input. The indicator clears after 1.5 seconds of inactivity.

## Mentions

Messages that mention you (`@username`) or `@everyone` are highlighted and may trigger browser notifications (if enabled).

## Do Not Disturb

Set your status to **Do Not Disturb** to suppress notification indicators. See [Accounts](accounts.md) for status settings.
