# Bookmarks & Pins

## Pinned Messages

Pin important messages to make them easily accessible in a channel.

### Pinning a Message

Right-click a message → **Pin** (requires `manageMessages` permission). Pinned messages record who pinned them and when.

### Viewing Pinned Messages

Click the **pin icon** in the channel header to view all pinned messages in that channel.

### Unpinning

Right-click a pinned message → **Unpin** (requires `manageMessages` permission).

## Bookmarks

Bookmarks are personal — only you can see your bookmarked messages.

### Bookmarking a Message

Right-click a message → **Bookmark** to save it to your personal bookmarks list.

### Viewing Bookmarks

Access your bookmarks from the bookmarks panel. Bookmarks are stored per-user and persist across sessions.
