# Direct Messages

Nexus supports 1:1 direct messages and group DMs.

## Starting a DM

1. Click on a user's avatar or username anywhere in Nexus
2. Click **Send Message** on their profile card
3. Type and send your message

Alternatively, use the DM section in the sidebar to start a **New Conversation** by entering a username.

## DM Interface

DMs appear in a virtual "Personal Server" in your sidebar. Each DM conversation shows:
- The other user's avatar and username
- Last message preview
- Unread message indicator
- Sorted by most recent activity

## Group DMs

Create group conversations with 3 or more participants:

1. Click **New Group DM** in the DM section
2. Add participants by username (2–50 participants, no duplicates)
3. Optionally set a group name (1–100 characters)
4. Click **Create**

Group DM features:
- Auto-named based on participant usernames if no name is set
- Any participant can add new members
- Leave a group DM at any time

## Message Requests

When someone you haven't messaged before sends you a DM, it appears as a **message request**. You can accept or decline.

## DM Calls

Start a voice or video call directly from a DM conversation. See [Voice & Video](voice-and-video.md) for details.

## E2E Encryption

1:1 DMs support end-to-end encryption using X25519 key exchange and NaCl/libsodium. See [Encryption](../security/encryption.md).

## Rate Limits

- DM creation: 10 per 60 seconds
- Group DM creation: 5 per 60 seconds
- Participant management: 20 per 60 seconds
