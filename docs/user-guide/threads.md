# Threads

Threads allow focused conversations branching from a specific message.

## Starting a Thread

Click the **Reply** button on any message to create a threaded reply. The original message is shown as context above your reply, and the thread is linked via the `reply_to` field.

## Viewing Threads

Thread replies appear inline in the channel with a visual indicator linking back to the parent message. Click the thread indicator to jump to the original message.

## Thread Behavior

- Threads share the same channel permissions as the parent message
- Reactions and attachments work the same as regular messages
- Thread messages appear in search results with their parent context
- Deleting a parent message does not delete thread replies
