# Web App

The web app is the primary Nexus client, served via Nginx.

## Browser Support

| Browser | Minimum Version |
|---------|----------------|
| Chrome / Chromium | 80+ |
| Firefox | 78+ |
| Safari | 14.1+ |
| Edge | 80+ |

WebRTC support is required for voice and video features.

## Access

Navigate to your Nexus instance URL (default: `http://localhost:3000`).

## Features

All Nexus features are available in the web client, including:
- Text and voice channels
- Direct messages and group DMs
- Screen sharing
- Theme customization
- File attachments and GIF picker

## PWA Support

Nexus includes PWA icons (192px and 512px) for adding to your home screen on mobile browsers.
