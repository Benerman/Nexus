# Custom Emoji

Upload custom emoji to your server for use in messages and reactions.

## Uploading Emoji

1. Go to **Server Settings → Emoji**
2. Click **Upload Emoji**
3. Select an image file
4. Set a name for the emoji

Requires `manageEmojis` permission.

## Rate Limits

Emoji uploads are limited to **5 per 60 seconds**.

## Using Custom Emoji

Custom emoji are available to all server members in:
- The emoji picker (message composer)
- The reaction picker
- Inline with `:emoji_name:` syntax

## Managing Emoji

View, rename, or delete custom emoji in **Server Settings → Emoji**.
