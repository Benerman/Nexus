# AutoMod

Nexus includes automated moderation rules to help manage your server.

## Available Rules

### Keyword Filter

Block messages containing specific words or phrases. Configure a list of blocked terms — messages matching these terms are automatically deleted.

### Spam Detection

Detect and block repetitive messages, excessive mentions, or rapid message posting.

### Invite Link Blocking

Automatically remove messages containing invite links to other servers.

## Configuration

Access AutoMod settings in **Server Settings → AutoMod** (requires `manageServer` permission).
