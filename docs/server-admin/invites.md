# Invites

Server invite links allow new members to join your server.

## Creating an Invite

1. Right-click the server name or go to **Server Settings → Invites**
2. Click **Create Invite**
3. Configure options:
   - **Max uses** — How many times the link can be used (0 = unlimited)
   - **Expiration** — When the invite expires
4. Share the generated link

Requires `createInvite` permission (enabled for @everyone by default).

## Managing Invites

View all active invites in **Server Settings → Invites**. Each invite shows:
- Invite code/link
- Creator
- Uses / max uses
- Expiration date
- Creation date

## Revoking Invites

Click **Delete** on an invite to revoke it immediately. The link will no longer work.
